# My Dance Record Datenschutzerklärung

Diese App erfordert kein Konto und erhebt, verfolgt oder übermittelt keine personenbezogenen Daten.

Alle Informationen, Bilder und Dateien, die der App hinzugefügt werden, werden lokal auf dem Gerät der Nutzerin oder des Nutzers gespeichert. Es werden keine Daten auf externe Server hochgeladen oder an Dritte weitergegeben.

Die App verwendet keine Analyse-, Werbe- oder Tracking-Technologien.

Nutzerinnen und Nutzer können Fotos oder Dateien über die standardmäßigen Teilen-Funktionen von Apple teilen. Jede Weitergabe wird ausdrücklich von der Nutzerin oder dem Nutzer gestartet und durch das jeweils gewählte Ziel kontrolliert.
